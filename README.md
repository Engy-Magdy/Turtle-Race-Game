# 🐢 Turtle Race Game

> A chaotic, interactive Python game where slow reptiles decide your fate. Built with the native `turtle` and `random` modules because standard board games just aren't stressful enough. 

---

## ✨ Features
* **Questionable Life Choices:** Pick your favorite colored turtle via a graphical prompt and blindly trust it with your emotional well-being.
* **Absolute Chaos:** Real-time random movement generation that completely ignores all laws of physics and common sense.
* **Instant Regret:** Dynamic win/loss screen rendering with automatic screen clearing (`window.clear()`) to wipe away the evidence of your poor betting skills.
